## 原生IP、ISP IP、住宅IP 到底差在哪

原生IP的定义不复杂：IP 归属地和服务器实际所在地一致，由当地 ISP 直接分配。香港服务器拿到香港本地运营商分配的段，WHOIS 和地理库都显示香港，这叫原生。广播IP 是从别处借来、广播到香港的地址，实际归属可能是美国、日本或数据中心持有段，流媒体和风控平台把它识别成机房 IP 的概率很高。

香港原生IP稀缺，原因在香港本地 ISP 分给数据中心的地址资源有限，能拿到再分给用户的服务商不多。

但原生IP不等于住宅IP。ISP IP 是本地运营商分配给机房的段，归属地正确，WHOIS 也显示香港本地运营商，风控库仍可能把它标成 hosting。住宅IP 是家宽段，平台眼里更接近真实家庭用户。丽萨主机的 CMI 线是 ISP IP，iCable 和 HGC 才是双ISP住宅IP，这三个词在同一家产品线里就不是一回事。买流媒体和票务，先问“是不是住宅段”，只问“是不是原生”不够。

## 买完怎么验：四步查清香港原生IP真假

第一步，开机器后访问 ipinfo.io 或 ip.sb，看 `country` 是不是 HK，`org` 是不是香港本地运营商。如果 org 显示美国、日本或明显的数据中心公司名，基本不是香港原生。

第二步，查 WHOIS 和 ASN。看 IP 段注册地、ASN 归属，确认它不是从别的地区广播过来的地址。WHOIS 显示香港、ASN 对应香港本地运营商段，才算过了归属地这一关。

第三步，用 Scamalytics、IPQualityScore 这类风控库查评分和标签。评分越低越好；出现 hosting、data center、proxy、VPN 标签，说明它至少不是干净的住宅IP。原生IP可能过得了归属地检查，过不了这一关。

第四步，用目标平台实测。TVB、Cityline、Netflix 港区、TikTok 逐个登录看限制。平台风控会变，商家截图只能参考，自己测出来的结果才算数。买之前把退款窗口留够，别在超过退款期之后才发现 IP 不能用。
